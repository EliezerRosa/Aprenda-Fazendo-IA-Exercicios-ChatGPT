# Aprenda Fazendo - HTML, CSS e JavaScript

Uma plataforma interativa e reativa para aprender desenvolvimento web. Escreva código HTML, CSS e JavaScript e veja o resultado imediatamente!

## Características

- **Editor de código interativo** com abas separadas para HTML, CSS e JavaScript
- **Visualização em tempo real** - suas alterações aparecem instantaneamente
- **Exemplos prontos** incluindo:
  - Formulários interativos
  - Animações CSS
  - Jogos em JavaScript
- **Menu de navegação** com acesso a:
  - Exercícios avançados
  - ChatGPT para suporte de IA
  - Cursos online recomendados
- **Interface responsiva** que funciona em desktop e mobile

## Como usar

1. Abra o `index.html` em seu navegador
2. Escolha uma aba (HTML, CSS ou JavaScript) para editar
3. Digite seu código nos editores
4. Veja o resultado imediatamente no painel de visualização
5. Experimente os exemplos prontos clicando nos botões verdes
6. Use o menu superior para acessar recursos externos

## Exemplos incluídos

- **Básico**: Introdução com botão interativo
- **Formulário**: Exemplo de formulário com validação
- **Animação CSS**: Demonstração de animações e efeitos
- **JavaScript Interativo**: Jogo de adivinhação de números

Perfeito para iniciantes que querem aprender fazendo!
